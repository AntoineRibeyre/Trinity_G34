## 📦 Clonage du dépôt

Pour cloner le dépôt et installer toutes les dépendances dans un environnement virtuel :

---

### 🔧 Création d’un environnement virtuel

**MacOS / Linux:**
```bash
python3 -m venv .venv
```
**Windows:**
```windows
python -m venv .venv
```

### ▶️ Activation de l’environnement virtuel
**MacOS / Linux:**

```bash
source .venv/bin/activate
```
**Windows:**

```Windows
.\.venv\Scripts\activate
```
